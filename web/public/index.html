      Study results

      The project used 6,056 MRI images for three experiments.

      The anomaly test

      Accuracy fell to 50% when glioma images were split before training. Evaluation used 400 held-out glioma crops and 4,052 other crops.

      A convolutional autoencoder learned from 128 × 128 grayscale glioma images. PCA compressed its latent activations to 100 components, then Mahalanobis distance measured how far each image fell from the training distribution. This branch used a separate representation from ResNet50.

      The study retained the autoencoder, PCA, and distance rule after removing the train–test overlap. This result cannot isolate why separation was weak.

      ResNet50 clustering

      The corrected analysis kept source labels separate from cluster assignments and reached an Adjusted Rand Index of 1.00. Average-pooled ImageNet features map each 512 × 512 crop to 2,048 numbers. The experiment averaged those features by filename-derived scan ID before fitting three K-means clusters.

      The groups are filename-derived. The observed separation comes from this collection and has not been evaluated on data from another scanner or hospital.

      Supervised classification

      The 900-tree random forest reached 72.7% accuracy and 0.729 F1 in the original run. The study reduced flattened grayscale pixels to 1,000 principal components, then compared logistic regression, K-nearest neighbors, and random forest.

      PCA was fit before the split and settings were explored on the test set. The original loop read 2,004 images per class, leaving 44 images from the “Tumor” folder unused. The preserved score is a historical baseline.

      Image processing and comparison

      How the explorer prepares an image and finds nearby groups.

      1. Prepare the crop

        Resize to 512 × 512 using the original nearest-neighbor sampling. Convert RGB to BGR and subtract the ImageNet channel means.

      2. Extract features

        Run the Keras ImageNet ResNet50 backbone without its classification head. Global average pooling produces one 2,048-dimensional vector.

      3. Compare groups

        Rank the original scan-group mean vectors by cosine distance. The dataset label belongs to the closest reference group. Published examples exclude their own group from matching.

      “Tumor” is the dataset’s folder label. The explorer is for de-identified research crops. Similarity to a reference group does not establish a diagnosis.
