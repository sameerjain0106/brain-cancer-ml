    Three approaches, three results

    Correcting the evaluation changed the story as much as the model choices did.

    Historical accuracy

    Supervised classification

    Flattened grayscale pixels were reduced to 1,000 principal components, then classified with logistic regression, K-nearest neighbors, and random forest. The 900-tree forest reached 72.7% accuracy and 0.729 F1 in the original run.

    PCA was fit before the split and settings were explored on the test set. The original loop read 2,004 images per class, leaving 44 images from the “Tumor” folder unused. Treat the preserved score as a historical baseline.

    ResNet50 clustering

    Average-pooled ImageNet features map each 512 × 512 crop to 2,048 numbers. The experiment averaged crops by filename-derived scan ID and fit three K-means clusters. The corrected analysis kept source labels separate from cluster assignments. All 603 groups aligned with their source classes in that fit.

    This is separation within one dataset. The groups are filename-derived and the study has no external scanner or hospital validation.

    Autoencoder anomaly detection

    A convolutional autoencoder learned from 128 × 128 grayscale glioma images. PCA compressed its latent activations to 100 components, then Mahalanobis distance measured how far an image fell from the training distribution. This branch used no ResNet50 features.

    Splitting glioma images before training removed overlap between training and evaluation. Accuracy dropped to 50%. The study retained the autoencoder, PCA, and distance rule, so the result alone cannot isolate what caused the weak separation.

    How the explorer works

    The site compares learned features with the original dataset references.

    1. Prepare the crop

      Resize to 512 × 512 using the original nearest-neighbor sampling. Convert RGB to BGR and subtract the ImageNet channel means.

    2. Extract features

      Run the Keras ImageNet ResNet50 backbone without its classification head. Global average pooling produces one 2,048-dimensional vector.

    3. Compare groups

      Rank the original scan-group mean vectors by cosine distance. The dataset label belongs to the closest reference group. Published examples exclude their own group from matching.

    “Tumor” is the dataset’s folder label. Similarity, cluster membership, and statistical novelty do not establish a medical diagnosis. The web comparison uses dataset references; the original classification and anomaly experiments are documented above.
